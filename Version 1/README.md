### M3 screws
You will need 62 screws for case. (64 if using the VReg fan mount https://www.printables.com/model/1391887-nerdqaxe-vreg-clip-and-60mm-fan-mount)

I used M3 between 5 and 8mm long should work. 8mm long works best in my opinion. Thread pitch of 0.5mm should work great. Searching M3x5 or M3x8 should easily find the right screws. I'll leave it up to you which screw head you like best. I had button head screws on hand already so that's what I went with
